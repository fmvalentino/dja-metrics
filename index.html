Methodology

Full-text search on NASA ADS for “Dawn JWST Archive” or the standalone acronym “DJA”, published or on arXiv since 2023. Each hit is scored from its highlighted context to separate genuine archive use from a person's initials or an unrelated match, then reviewed by hand where the automatic score is ambiguous. Runnable example, reproducing the numbers above end to end: dja_discovery_example.ipynb. To see this same search running live on ADS right now, with only the false positives already caught excluded — rather than the fixed, hand-checked library above — use this link.

Because the count above comes from a live search rebuilt from scratch every month, a paper can briefly vanish from it around the moment it gets journal-published: ADS retires its arXiv listing and assigns a new bibcode, but the new record's full text usually isn't searchable again for a few days. When that happens the paper is recovered automatically by matching its title against what was confirmed in the previous run, so the count stays complete rather than dipping for a few days each time — the fixed library above never has this problem at all, since it's a static list rather than a live search.
