The library is a fixed list that we update by hand when possible, so it can lag slightly behind the monthly count above. Methodology

We search the full text of the papers in NASA ADS for “Dawn JWST Archive” and for the acronym “DJA” on its own, in journal articles and arXiv preprints from 2023 onwards. Every match is scored from the passage in which it appears, so that genuine use of the archive can be told apart from a person's initials in the acknowledgements or from an unrelated acronym, and the uncertain cases are read by hand. The notebook dja_discovery_example.ipynb reproduces every number on this page from start to finish. The same search can also be run live on ADS through this link, which already leaves out the false matches we have found; unlike the library above, it also shows recent papers that nobody has checked yet.

When a preprint is published in a journal, ADS replaces its arXiv identifier with a new one, and for a few days the new record cannot be found by the full-text search. The monthly update recognises these papers by their title in the previous run and keeps them in the count, so the number does not drop in the meantime. The library above is not affected, because it is a fixed list.
